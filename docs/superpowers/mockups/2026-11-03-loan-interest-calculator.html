A. 서민금융 상세 · 금리 범위형 자동 적용 (예: 버팀목전세자금 · irt "2.1~2.9" · 만기일시상환, 혼합상환)

한눈에 (기존)

금리2.1~2.9%
금리구분변동금리
상환방식만기일시상환, 혼합상환

설계 메모 · 위치: '한눈에' 카드 바로 아래 · 범위형은 [최저][최고] 칩, 기본은 최고금리(보수적) · 상환방식이 여러 개면 '만기일시상환을 고른 경우 기준' 문구 · 기간 기본값은 원천 최대 총 대출기간(정수 1~10)일 때만, 아니면 2년

B. 서민금융 상세 · 비정형 금리 → 직접 입력 (예: 경영안정지원자금 · irt "은행금리-1.8" · 한도 5억)

설계 메모 · 금리 칸은 비워 두고 원문("은행금리-1.8")을 그대로 보여 줌 · 임의 값 자동 입력 없음 · 상품 한도가 있으면 한도 초과 빠른선택 칩 비활성 + '상품 한도' 칩(누를 때만 입력)

C. 맞춤 전세보증 상세 · 금리·금액 모두 직접 입력 (예: 무주택 청년 특례전세)

우대 · 이자지원 (기존)

이자 지원: 최대 연 2.8%p

설계 메모 · 위치: '우대·이자지원' 아래, '지역별 최대 임차보증금' 위 · 보증한도·한도비율을 금액에 넣지 않음, 한도 칩 없음 · 금리 기본값 없음, '이 보증상품의 금리가 아님' 명시 · 이자지원(%p)은 계산에 반영하지 않음

D. 모바일 375px (A와 동일 컴포넌트)

설계 메모 · 단일 금리(예: 우리 청년맞춤형 전세대출 3.47%)는 자동 입력 + '상품 안내 금리' 표시 · 입력란 16px(iOS 확대 방지) · 칩·버튼 34~46px 터치영역 · 이 화면만 시안 설명용으로 금액 1억을 미리 넣음(실제는 빈 칸)

E. 별도 수정 — 금리 단위(%) 누락 (계산기와 분리된 작은 수정)

순수 숫자·범위형에만 % 부착. "은행금리-1.8", "기준금리 + 2.5", "연 2.51% (…)"처럼 설명·단위가 있는 값은 원문 그대로.
