# 실거래가 목록 페이지네이션 재설계 — 설계 문서

- 날짜: 2026-06-07
- 대상 컴포넌트: `components/ui/pagination.tsx` (공유), `app/(public)/list/_components/pagination-nav.tsx`
- 범위: 페이지네이션 UI/UX 개선 **만**. 인피드 광고·스티키 사이드바 광고는 별도 후속 작업.

## 배경 / 문제

실거래가 목록(`/list`)은 71,648건 · 2,389페이지 규모. 현재 페이지네이션의 문제:

- 페이지 수가 많아 숫자 기반 점프의 활용도가 낮음
- 현재 페이지 위치 인지가 어렵고 가독성이 낮음
- `« ‹ › »` 아이콘 버튼의 의미가 직관적이지 않음
- 총 건수 영역(상단 카드)과 위치/페이징 영역이 시선상 분리되어 경쟁

## 결정된 방향

탐색 패러다임은 **URL 기반 페이지네이션 유지**(서버 컴포넌트 + `?page=`). 무한 스크롤·로드모어는 채택하지 않음.

근거 (AdSense 관점 포함):
- AdSense 정산은 **viewable impression × RPM** 기준. `다음` 클릭마다 새 pageview = 새 광고 노출이 발생해 페이지네이션이 노출량에서 가장 유리.
- 무한 스크롤은 단일 pageview·낮은 viewability·정책 리스크(광고 lazy-load 요구)로 최악.
- 체류시간 자체는 직접 정산 대상이 아님 — "체류시간만" 최적화는 함정.
- 실제 수익 레버(인피드 광고·스티키 사이드바)는 **이번 범위 밖**, 후속 작업.

## 적용 위치 (Blast radius)

`components/ui/pagination.tsx`는 7개 표면에서 공유: list, urban, amenity, subscription, childcare, school, apt 상세 거래 테이블(`unified-transaction-table.tsx`).

- 재설계는 **공유 컴포넌트**에 반영 → 7개 표면 일관 적용. (list 전용 fork 미채택: 중복·불일치 비용 큼)
- 빠른 이동(`+10`, `마지막 N`) 등 규모 의존 UI는 **조건부 렌더** → 페이지 적은 표면(childcare 등, apt 테이블)에서는 `이전 / 번호 / 다음`만 노출되어 과밀하지 않음.
- 기존 graceful degradation 유지: `totalPages <= 1` → 아무것도 렌더하지 않음.

## 데스크톱 푸터 (선택안 A)

```
검색 결과 71,648건 · 31–60 표시중
[‹ 이전]  1  [2]  3  4  5  [다음 ›]   ·   [+10 ⟫]  [마지막 2,389 ⟫]
```

- `이전`/`다음`: 글자+chevron, outlined Primary Blue, 높이 46px, 의미는 항상 **1칸 이동**.
- 페이지 번호: 최대 5개. 현재 페이지 = solid Primary Blue 배경 + 흰 글자, 나머지 = 회색 글자 / soft hover. 클릭 영역 ≥ 44px.
- 빠른 이동: `+10 ⟫`(현재+10, `totalPages`로 clamp), `마지막 N ⟫`(실제 마지막 페이지 번호 노출). 약하게 처리(secondary), divider로 분리.
- **후방 대칭(조건부 렌더)**: 깊은 페이지에서 좌측에 `⟪ 처음` / `⟪ -10` 미러 노출.
  - `처음`: 현재 번호 윈도우에 1페이지가 포함되지 않을 때.
  - `-10`: `current > 11`일 때.
  - 앞쪽(초반) 페이지에서는 노출하지 않아 깔끔함 유지.

## 모바일

```
[이전]      2 / 2,389      [다음]
```

- 가운데 `2 / 2,389`는 **탭 가능 → 페이지 점프 입력**(number 입력 + `이동` 버튼) 노출. 임의 페이지·마지막 페이지 접근을 과밀 없이 제공.

## 카운트 강조

- 상단 결과 카드는 **총 N건**을 큰 강조로 유지(`property-list.tsx` 기존 카드).
- 푸터 캡션은 위치 단서(`31–60 표시중`)로, 컨트롤 **위 중앙**에 배치(기존 우측 정렬 → 중앙). 총건수/위치가 시선상 경쟁하지 않도록.

## 엣지 케이스

- `totalPages <= 1` → 렌더 없음.
- 비활성: `이전`(1페이지), `다음`/`+10`/`마지막`(마지막 페이지) → 연한 회색 + `disabled`.
- `+10`은 `totalPages`로 clamp. 빠른 이동 클러스터는 `totalPages <= 5`이면 전체 숨김.
- 페이지 번호 표기는 `toLocaleString('ko-KR')`.

## 접근성 / 사이징

- 글자 라벨 기반 `aria-label`: "이전 페이지", "다음 페이지", "10페이지 뒤로", "10페이지 앞으로", "마지막 페이지로", "처음 페이지로".
- 현재 페이지에 `aria-current="page"`.
- 모든 인터랙티브 타깃 ≥ 44px.
