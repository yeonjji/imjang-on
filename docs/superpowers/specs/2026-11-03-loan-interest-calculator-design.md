1. **`irt` 단위 확인 완료** — 공공데이터포털 15106208 페이지에 내장된 Swagger `definitions.item.properties.irt.description = "금리(연, %)"`. 자동 적용 유지. (같은 명세: `maxTotLnTrm`=(최대)총대출기간(연), `prftAddIrtCond`=우대금리·가산금리 조건, 갱신주기 '연간')
2. **대출기간 기본 2년으로 통일**(상품 `maxtotlntrm` 미사용), 라벨 "대출기간 (계산을 위한 가정)".
3. **입력 검증**: 금액은 숫자만·만원 정수·최대 1,000,000만원(100억, 초과 입력은 받지 않음). 금리는 정수 2자리·소수 2자리·0.01~30%, 벗어나면 결과 대신 안내. 서민금융 상품 한도 초과 시 경고 문구(계산은 표시).
4. **월 이자 차이 문구에서 '몇백~몇천 원' 단정 제거** → "은행의 일할 계산 방식(대출 일수 기준)과 납입일에 따라 이 금액과 다를 수 있습니다."

## 1. 목표와 범위

두 상세화면에 같은 계산 컴포넌트를 붙인다. 계산은 만기일시상환(매달 이자만, 원금은 만기 일시) 하나뿐이다.

| | 서민금융 상세 `/finance/[seq]` | 맞춤 전세보증 상세 `/jeonse-guarantee/[grntDvcd]` |
|---|---|---|
| 제목 | 대출 이자 계산기 | 전세대출 예상 이자 계산기 |
| 노출 대상 | 상환방식에 '일시' 포함 + 무이자 아님 → **85건** | **47건 전부**(상품명 모두 '전세' 포함 실측) |
| 금리 | 원천 금리가 숫자면 자동, 범위면 최저·최고 선택, 그 외 직접 입력 | 항상 직접 입력(기본값 없음) |
| 한도 | 상품 한도(`lnlmt`) 안내 + 한도 초과 빠른선택 비활성 + '상품 한도' 칩 | **연결하지 않음**(보증한도를 대출금액으로 쓰지 않음) |
| 위치 | '한눈에' 카드 바로 아래 | '우대·이자지원' 카드 아래, '지역별 최대 임차보증금' 위 |

**하지 않는 것(1차):** 원리금·원금균등 분할상환 계산, 우대금리·이자지원 차감, 보증료 계산, 전세보증 평균금리 연동(HF `jnse-grtd-loan-rat-list-v2`), 저장·공유, 서버 API.

| 항목 | 필드 | 상태 |
|---|---|---|

| 금리구분 | `irtCtg` | 고정/변동/무이자 등 |
| 한도 | `lnlmt` (만원) | |

| 상환방식 | `rawJson.rdptmthd` 텍스트 | '일시' 포함 87건, 그중 분할·혼합 병기 46건 |

### 2.2 맞춤 전세보증 `JeonseGuaranteeProduct` 47건
금리 필드 없음(보증상품). `intSprtCont`(이자지원 %p) 텍스트만 있음 → 계산에 쓰지 않는다.

### 2.3 ⚠️ 구현 전 확인 필요 — `irt`의 단위·의미
공식 명세(공공데이터포털 B553701 활용가이드)를 아직 확인하지 못했다(웹 검색으로 명세 미발견).
데이터상 근거: 설명형 값이 `연 2.51%`, `(보증금)연1.3%`로 적혀 있고, 숫자형 최대 19.99·범위 최대 8.97로 연 %와 맞다.
→ **구현 착수 전 활용가이드에서 `irt` = 연 금리(%) 확인**. 아니면 자동 적용을 끄고 전부 직접 입력으로 떨어뜨린다.
범위형 `a~b`는 최저~최고로 해석한다(같은 확인 대상).

## 3. 금리 자동 적용 규칙 (서민금융만)

`parseLoanRate(irt, irtCtg)` → 아래 셋 중 하나. 공백 trim 후 판정.

| 원문 | 결과 | 화면 |
|---|---|---|
| `^\d+(\.\d+)?$` 이고 0 < 값 ≤ 30 | `single` | 자동 입력 + "상품 안내 금리 3.47%를 넣었습니다" |
| `^\d+(\.\d+)?\s*~\s*\d+(\.\d+)?$` 이고 0 < 최저 ≤ 최고 ≤ 30 | `range` | [최저][최고] 칩, **기본 최고**(보수적) |
| 그 외(빈 값·`~3.28`·`은행금리-1.8`·`%`·설명 포함) | `manual` | 빈 칸 + 원문 그대로 노출("자동으로 넣지 않았습니다") |
| `0` 또는 `irtCtg`에 '무이자' | — | 계산기 미노출 |

`~3.28`(상한만)은 최저가 없어 자동 적용하지 않는다(임의 값 금지).

## 4. 노출 판정 (서민금융)

`isBulletRepayment(rdptmthd)` = 텍스트에 '일시' 포함. 분할·혼합이 함께 적혀 있으면(`mixed`) 부제에 "만기일시상환을 고른 경우로 계산" 문구.
무이자(§3)는 미노출. 상환방식 '-'·빈 값은 미노출.

## 5. 공통 계산·UI

### 5.1 계산 (순수 함수, 원 단위 반올림)
- 월 이자 = P × r ÷ 100 ÷ 12
- 연간 이자 = P × r ÷ 100
- 기간 총이자 = P × r ÷ 100 × 년수
- 상승 비교: r+0.5, r+1.0 각각의 월 이자·증가액·기간 총이자·증가액

시안 검증값: 2억 × 2.9% → 월 483,333원 · 연 5,800,000원 · 2년 11,600,000원. 1억 × 3.47% → 월 289,167원.

### 5.2 입력
- **대출금액**: 만원 단위 숫자 입력(천 단위 콤마 자동), 아래 "1억 5,000만원" 읽기 문구. 시작값 없음(빈 칸).
  빠른선택 5,000만·1억·1.5억·2억·3억. 서민금융은 `lnlmt` 초과 칩 비활성 + '상품 한도 N' 칩(누를 때만 입력). 유효 1~1,000,000만원.
- **연 금리**: 소수 둘째 자리까지, 0 초과 30 이하. 자동 적용된 값도 수정 가능.
- **대출기간(가정)**: 1~10년 선택. 기본값 = `maxtotlntrm`이 1~10 정수면 그 값, 아니면 2년(계산 가정, 상품 데이터 아님 — 라벨에 '가정' 명시).
- 금액·금리 중 하나라도 비면 결과 대신 "대출금액과 연 금리를 입력하면 예상 이자를 보여 드립니다."

### 5.3 결과·안내
- 예상 월 이자(크게) → 연간 예상 이자 · N년간 예상 총이자 → 접힘: "금리가 오르면 얼마나 늘어날까요?" 표.
- 안내(항상): 예상 금액이며 실제 이자는 일수 기준 일할 계산으로 달마다 다름 / 보증료·인지세 등 부대비용·우대금리 미반영.
- 변동금리면 + "기간 중 금리가 바뀌면 이자도 바뀜".
- 전세보증 전용: "이 보증상품에는 대출금리가 정해져 있지 않음 — 은행 안내 금리 입력", "실제 대출 가능 금액은 보증한도와 별개로 소득·보증금·은행 심사", 이자지원 미반영.
- 출처: 서민금융 "금리: 서민금융진흥원 대출상품한눈에 · 수집일 YYYY-MM-DD"(manual이면 "상품 안내 금리: …"). 전세보증은 숫자 출처가 사용자 입력이라 출처 줄 없음.
- 문체: 존댓말(시안 초안의 반말 제거). 본문 14px 이상, 입력 16px(iOS 확대 방지), 결과 영역 `aria-live="polite"`, 칩 `aria-pressed`.
