## 1. 표본 실측 (2026-10-27, 경상남도 전체)

- **API:** 국립중앙의료원_전국 병·의원 찾기 서비스(data.go.kr 15000736) `B552657/HsptlAsembySearchService/getHsptlMdcncListInfoInqire`. 기존 `PUBLIC_DATA_KEY`(개발계정)로 승인 완료. 이용허락 제한 없음.
- **호출량:** `numOfRows=5000`이 동작한다(경남 4,199건을 한 번에 2.3초). 전국 약 8만 건이면 약 16회.
- **채움률:** 경남 4,199곳 중 4,192곳(99.8%)에 요일별 진료시간이 있다.

## 2. 데이터 모델

```prisma
/// 국립중앙의료원 병·의원 찾기에서 받은 진료시간. 심평원(HospitalDetail)과 섞지 않는다.
model HospitalNemcHours {
  hospitalId BigInt   @id
  hospital   Hospital @relation(fields: [hospitalId], references: [id], onDelete: Cascade)
  hpid       String   @db.VarChar(20)
  openMon Int?  closeMon Int?  openTue Int?  closeTue Int?  openWed Int?  closeWed Int?
  openThu Int?  closeThu Int?  openFri Int?  closeFri Int?  openSat Int?  closeSat Int?
  openSun Int?  closeSun Int?  openHol Int?  closeHol Int?
  note       String?  @db.VarChar(300)   // dutyEtc
  fetchedAt  DateTime                    // 화면의 '조회일'
}
```

- `HospitalDetail`을 쓰지 않는 이유: 심평원 파일을 수동으로 다시 적재하면(ingest-hospital) 덮어써지고, 요일마다 출처가 섞인다.
- RLS 문은 넣지 않는다(OCI 자가호스팅 이후 마이그레이션 관례, 예: 20261021 SubscriptionResult).

## 3. 수집

- `scripts/ingest/hospital-nemc/runner.ts`. `Q0` 없이 전국을 `numOfRows=5000`으로 페이지 순회한다.
- 기존 `ev-status` 교훈 반영: 호출마다 시간 제한(30초)·1회 재시도, `resultCode≠00`이면 실패로 기록하고 중단.
- **매칭** (`lib/hospital/nemc-match.ts`, 순수 함수):
  1. 정규화 이름(공백·괄호 제거) + 도로명 주소(괄호·쉼표 뒤 제거, 공백 정리)가 같은 우리 병원이 정확히 1곳
  2. 1이 없으면, 정규화 이름 + 전화번호(숫자만)가 같은 곳이 정확히 1곳
  3. 둘 이상이면 버린다(잘못 붙이는 것보다 비워 두는 게 낫다)
- **반영:** 매칭된 행 upsert. 실행이 **끝까지 성공했을 때만** 이번에 보지 못한 행을 지운다(폐업·매칭 해제). 중간 실패면 지우지 않는다.
- **주기:** 주 1회(일요일 KST 04:00). `deploy/run-etl.sh`에 `hospital-nemc` 추가, `install-timers.sh`의 타이머 목록 **과 `systemctl start` 목록 둘 다**에 추가(하드코딩 함정).
- 결과 로그: 받은 건수, 매칭·미매칭·중복, upsert, 삭제. 0건이면 실패로 기록한다("OK · 0건" 함정).

## 4. 표시 규칙 (1안)

`lib/hospital/hours.ts`의 `effectiveHours(detail, nemc)` 하나가 정한다.

- 심평원 `HospitalDetail`의 요일 시작·종료 14칸(월~일) 중 **하나라도 값이 있으면** → 심평원 값만 쓴다(요일별로 섞지 않는다). 출처 `hira`. 기존 `with_hours` 집계와 같은 기준이라 화면과 SQL 집계가 같은 판정을 한다.
- 없고 `HospitalNemcHours`가 있으면 → 국립중앙의료원 값. 출처 `nemc`, 조회일 `fetchedAt`.
- 둘 다 없으면 → null(섹션 숨김, 기존 동작).

이 결과를 쓰는 곳(모두 같은 값을 보게 한다):

| 위치 | 파일 | 변경 |
|---|---|---|
| 진료시간 탭 | `hospital-tab-operation.tsx` | `effectiveHours` 결과로 요일표. 출처가 nemc면 공휴일 행, 안내(`note`), 출처 줄 표시 |
| 오늘 진료 카드 | `hospital-summary-cards.tsx` | 같은 결과에서 오늘 요일 |
| 상세 FAQ | `lib/faq/builders/hospital.ts` | 월요일 시간을 같은 결과에서 |
| 같은 진료과 주변 집계(진료시간 공개 수·토요일·평일 20시 이후) | `lib/hospital/context.ts` SQL | `HospitalNemcHours` LEFT JOIN, 심평원 요일 값이 하나라도 있으면 심평원, 아니면 nemc(같은 규칙을 SQL로) |
| 약국 상세 '주변 일요일 진료 의원 수' | `lib/pharmacy/context.ts` `countSundayClinicsNearby` | 같은 규칙 |

- 상단 요약 문장(`lib/insights/hospital.ts`)은 진료시간을 쓰지 않는다(2026-10-27 확인) → 변경 없음.
- 심평원 출처일 때 화면은 지금과 같다. 점심·일요일·공휴일 휴진 문구(`lunchWeekday` 등)는 심평원일 때만 나온다.
- nemc 출처일 때 진료시간 표 아래:
  `출처: 국립중앙의료원 전국 병·의원 찾기 · 2026-10-27 조회 · 진료시간은 바뀔 수 있으니 방문 전 전화로 확인하세요`
