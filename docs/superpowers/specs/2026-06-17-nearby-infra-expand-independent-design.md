# 주변 생활 인프라 — 더보기 시 클릭한 카드만 확장 (모바일 전용)

- 날짜: 2026-06-17
- 대상: 공용 `NearbyInfra` 컴포넌트(`components/ui/nearby-infra.tsx`) — 전 상세 페이지
- 관련: 직전 작업 `2026-06-17-nearby-infra-item-links-design.md`(같은 컴포넌트)
- 범위: **모바일만** (데스크탑은 현재 동작 유지)

## 배경 / 문제

각 인프라 카테고리 카드(`InfraBlock`)는 화면 cap 5개까지 보여주고 "+N곳 더보기"로 펼친다.
현재 그리드 래퍼가 `[grid-auto-rows:1fr]`라 **모든 행 트랙을 가장 큰 카드 높이로 균등화**한다.
결과적으로 한 카드에서 더보기를 누르면 그 카드가 제일 커지고 **나머지 카드들이 전부 같은 높이로 부풀어** 빈 공간이 생긴다.

이번 작업은 **모바일(1열)만** 고친다:
- 모바일에서 더보기를 누른 카드만 펼쳐지고, 나머지 카드는 자기 내용 높이 그대로 고정.

데스크탑(2열)은 **이번 범위에서 제외**한다(현재 동작 유지). 이유:
- 웹에서 카드가 자기 높이로 독립 확장되면, 같은 행의 옆 카드가 짧은 채 아래에 빈 공간이 생겨 **그리드가 깨져 보인다**.
- 웹에서 "모든 카드 균등"과 "하나만 인라인 확장"은 그리드 안에서 양립 불가. 균등을 유지하며 안 깨지게 하려면 더보기를 그리드 밖(오버레이/목록 이동)으로 빼야 하며, 이는 CSS가 아닌 별도 구현이라 추후 별도 결정한다.
- 현재 웹은 더보기 시 `1fr`로 카드들이 같이 커지지만 **균등은 유지**되어 깨지지 않으므로, 그대로 두는 것이 안전하다.

## 변경 사항 — `components/ui/nearby-infra.tsx` (1곳, CSS 클래스만)

### 그리드 래퍼 (현재 45행)

```tsx
// before
<div className="grid grid-cols-1 gap-3 [grid-auto-rows:1fr] md:grid-cols-2">
// after
<div className="grid grid-cols-1 gap-3 items-start md:grid-cols-2 md:[grid-auto-rows:1fr] md:items-stretch">
```

동작 원리:
- **base(모바일, <768px)**: `[grid-auto-rows:1fr]`을 제거하고 `items-start` 적용.
  - auto-rows가 내용 높이가 되고, `align-items: start`로 카드가 stretch되지 않음 → 각 카드는 자기 내용 높이.
  - 한 카드를 펼쳐도 그 카드의 행만 커지고 나머지는 그대로. 항목이 적은 카드에 빈 공간도 안 생김.
- **md(데스크탑, ≥768px)**: `md:[grid-auto-rows:1fr]` + `md:items-stretch`로 **현재 동작을 그대로 복원**.
  - (base에서 `items-start`로 바꿨으므로 `md:items-stretch`로 되돌려야 현재와 동일.)

### 변경하지 않는 것

- `InfraBlock` 카드 컨테이너(62행) 포함 그 외 전부 그대로: `expanded` state, `DISPLAY_CAP`, 더보기 버튼, `mt-auto` 푸터 정렬, 항목 Link/호버/화살표, 카테고리 배지줄, `SourceCaption`.
- JS·데이터·prop 변경 없음. min-height 등 카드 클래스 추가 없음.

## 동작 결과

| | 평소(rest) | 더보기 클릭 |
|---|---|---|
| 모바일(1열) | 각 카드 내용 높이 | **클릭한 카드만 확장, 나머지 고정** (변경) |
| 데스크탑(2열) | 모든 카드 동일 높이 | 모든 카드 같이 커짐(균등 유지) — **현재와 동일** |
