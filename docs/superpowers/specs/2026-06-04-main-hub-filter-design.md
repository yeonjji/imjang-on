# 메인화면 — 실거래가 필터 검색 + 유형 허브

작성일: 2026-06-04
브랜치: `feat/main-hub-filter`

## 목표

메인화면(`app/(public)/page.tsx`)을 실거래가 진입 허브로 재구성한다. 기존 히어로 문구와 "인기 아파트 단지" 그리드를 제거하고, 한 섹션에 **필터 검색 박스**(주인공)와 **유형별 허브 카드**(보조)를 좌우로 배치한다.

이번 작업 범위에서 제외: "우리동네 한눈에 보기" 섹션, 지도 기반 검색.

## 배경 / 데이터 제약

- `PropertyType` = `APARTMENT` / `OFFICETEL` / `ROW_HOUSE` / `MULTIPLEX`. `/list`의 `TYPE_MAP`에서 villa = `ROW_HOUSE` + `MULTIPLEX`.
- `DealType` = `SALE` / `JEONSE` / `WOLSE`.
- 단지·거래 데이터에 **위경도 좌표가 없음**(주소는 텍스트, 지역은 행정구역 코드 계층뿐). → 지도 영역 검색은 불가, 지역은 시도→시군구 드롭다운으로 처리.
- `/list` 페이지는 이미 완성형 필터를 가짐. URL 파라미터: `type`, `deal`, `price_min`, `price_max`, `area`, `sort`, `region`, `sido`, `page`. 메인 필터는 이 스키마로 URL을 만들어 `/list`로 보내는 역할만 한다.

## 레이아웃

`max-w-[1180px]` 컨테이너 안에 단일 섹션:

```
┌─ 컨테이너 ─────────────────────────────────────────────┐
│  ┌─ 필터 검색 박스 (flex-1) ─┐  ┌─ 허브 (w≈300px) ─┐  │
│  │  유형 / 거래 / 금액 / 평수 / 지역 │  │ 아파트 / 오피스텔 / 다세대 │  │
│  │        [ 🔍 검색 ]        │  │  (세로 카드 3개)    │  │
│  └──────────────────────────┘  └────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

- 데스크톱: `flex`, 왼쪽 `flex-1` / 오른쪽 `w-[300px]`.
- 모바일(<md): 세로 스택 — 필터 박스 위, 허브 카드 아래(좁으면 세로 정렬).
- `page.tsx`는 DB 쿼리 없음. `getSidoList()`로 시도 목록만 받아 필터에 props로 전달. 기존 인기 단지 쿼리·그리드·`PropertyCard` import 삭제.

## 컴포넌트 ① `MainSearchFilter` (신규, 클라이언트)

위치: `app/(public)/_components/main-search-filter.tsx`

- 상태는 로컬 `useState`로만 관리(URL 즉시 반영 X). `검색` 버튼 클릭 시에만 이동.
- props: 시도 목록(`getSidoList()` 결과).

필드 → `/list` 파라미터 매핑:

| 필드 | UI | 파라미터 | 값 |
|------|-----|----------|-----|
| 유형 | 칩 단일선택 | `type` | `all`(생략) / `apt` / `officetel` / `villa` |
| 거래유형 | 칩 단일선택 | `deal` | `all`(생략) / `sale` / `jeonse` / `wolse` |
| 금액 | 최소~최대 드롭다운 | `price_min` / `price_max` | 만원 단위. 거래유형 따라 범위 자동 조정(매매 ~20억 / 전세 ~10억 / 월세 보증금 ~2억) |
| 평수 | 칩 단일선택 | `area` | `small` / `medium` / `large` / `xlarge` |
| 지역 | 시도→시군구 드롭다운 | `sido` / `region` | 시군구는 `/api/regions?sido=` fetch |

동작:
- `검색` 클릭 → 값이 있는 파라미터만 모아 `router.push('/list?' + params)`. 기본값(`all`/빈값)은 생략.
- 아무것도 안 골라도 `검색` 누르면 `/list` 전체 목록으로 이동.
- 거래유형 변경 시 금액 드롭다운 범위가 바뀌고 기존 금액 선택은 초기화(`/list` 패널과 동일 규칙).

## 컴포넌트 ② 유형 허브 카드 (오른쪽 컬럼)

서버 컴포넌트로 충분(순수 링크). 세로 스택 3개:

| 카드 | 링크 | 부제 |
|------|------|------|
| 아파트 | `/list?type=apt` | 단지별 매매·전세·월세 실거래가 |
| 오피스텔 | `/list?type=officetel` | 오피스텔 실거래가 한눈에 |
| 다세대 | `/list?type=villa` | 연립·다세대 실거래가 |

- 각 카드: 아이콘 + 유형명(굵게) + 부제 + hover 효과.
- 디자인 톤: `/html/main.html` 목업 및 기존 컴포넌트 스타일(파란 계열 `--color-*` 토큰), `region-card.tsx` 참고.
