### 2. 상가 중복 — ⚠️ 두 가지 원인이 섞여 있음
- Store 353,669행 중 `updatedAt` 9/1(최신 수집) 320,455행, **7/1에 멈춘 행 33,214(9.4%)** = 9/1 수집에 없던 옛 레코드. 업종 전반에 고르게 분포(특정 업종 수집 실패 아님)
  - 그중 18,729행은 같은 주소·업종에 최신 레코드가 있음
- **E03 '잠실새내역' 카페(id 245275) = 옛 레코드**(7/1). 대체 레코드 id 887528 '스타벅스'+'잠실새내역'(9/1). → prune으로 해결

  - 완전 동일 이름 중복(예: '지에스25만년+엑스포점' ×2)
  - 표기 변형: '세븐…점'+'코리아' vs '세븐일레븐…점'(가장 흔함), '지에스25' vs 'GS25'

  - 같은 건물 다른 점포
  - → **주소만으로 병합하면 안 된다는 문서 경고가 맞음.** 브랜드 별칭 정규화 후 이름 완전 일치만 병합하는 좁은 규칙이 필요
