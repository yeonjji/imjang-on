현재 /list 페이지 — 개선 포인트

코드 분석 결과 발견한 4가지 주요 문제

1

모바일 필터 없음

hidden md:block → 모바일에서 사이드바 필터가 통째로 사라짐

모바일 사용자는 유형·가격 필터를 전혀 쓸 수 없음

2

지역 필터 UI 누락

URL에 ?region= 파라미터가 있지만 FilterPanel에 지역 선택 UI가 없음

시도 → 시군구 드릴다운 UI 자체가 미구현 상태

3

카드 정보 부족

최근 거래일, 가격 변동 추이(↑↓), 면적 정보가 카드에 없음

사용자가 클릭 전 판단할 수 있는 정보 부족

4

정렬 옵션 부족 + 로딩 없음

정렬: 최신거래순·거래많은순 2개뿐. 필터 변경 시 스켈레톤 없이 빈 화면

가격 높은순/낮은순 정렬 없음. UX 공백 발생

추가 개선 가능 항목

키워드 검색 (단지명) 가격 높은순/낮은순 정렬 필터 활성 상태 뱃지 표시 스켈레톤 로딩 모바일 바텀시트 필터
