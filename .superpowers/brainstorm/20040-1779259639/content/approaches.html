/list 페이지 개선 방향 선택

어떤 방향으로 개선할지 골라주세요

A

점진적 개선 빠름 · 안전

기존 구조는 유지하면서 문제 항목만 수정

  • 카드: 모바일에서 grid-cols-1 전환 (깨짐 수정)
  • 필터: 모바일 "필터" 버튼 → 바텀시트
  • 지역 필터: 시도→시군구 드릴다운 추가
  • 정렬: 가격 높은순/낮은순 추가
  • 페이지네이션: 모바일 간소화 (이전/다음 + 페이지수만)
  • 스켈레톤 로딩 추가
⏱ 예상 작업: 소·중형 태스크 6개
B

카드 + 필터 전면 재설계 권장

카드 레이아웃과 필터 UX를 새로 설계

  • 카드: 모바일 전용 레이아웃 + 최근거래일·가격추이(↑↓) 추가
  • 필터: 상단 가로 필터바(모바일) + 사이드바(데스크톱) 듀얼 모드
  • 지역 필터: 시도→시군구 드릴다운
  • 키워드 검색: 단지명 입력 필터 추가
  • 정렬 강화: 4가지 (최신/거래많은/가격높은/가격낮은)
  • 페이지네이션: 모바일 간소화 + "30개씩/50개씩" 선택
  • 스켈레톤 로딩 + 필터 활성 뱃지
⏱ 예상 작업: 중형 태스크 10~12개
C

테이블 뷰 + 모바일 퍼스트 대규모

카드 대신 테이블/리스트 뷰 전환 + 완전 모바일 퍼스트

  • 데스크톱: 테이블 뷰 (이름·지역·매매·전세·월세·거래수 컬럼)
  • 모바일: 세로 카드 스택, 스와이프로 필터
  • 뷰 전환 토글 (카드 ↔ 테이블)
  • B의 모든 기능 포함
  • 무한 스크롤 (페이지네이션 대체 옵션)
⏱ 예상 작업: 대형 태스크 15개+
💡 추천: B안 — 카드 깨짐·모바일 필터·지역 필터가 모두 해결되고, 키워드 검색과 정렬 강화까지 묶어 한 번에 완성도를 높일 수 있어요.
