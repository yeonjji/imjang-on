# 요약 보고서 — imjangon.co.kr 애드센스 'thin content' 거절 진단 및 개선안

> 작성일 2026-07-01 · 방법: Firecrawl 기반 사이트 크롤링 + 구글 공식 정책·비교 사례 리서치

## 한 줄 결론

imjangon.co.kr이 '가치 없는 콘텐츠(low-value/thin content)'로 거절되는 **핵심 원인은 콘텐츠 품질이 나빠서가 아니라, 사이트의 대다수 페이지가 공공데이터 피드에서 자동 생성된 "표·수치 덩어리"이고 페이지마다 고유한 서술형(문장) 부가가치가 눈에 보이지 않기 때문**입니다. 구글은 이런 패턴을 '규모화된 콘텐츠 남용(Scaled content abuse)'과 '스크래핑'으로 분류합니다. 즉 **"사람에겐 유용하지만, 크롤러 눈엔 원본 텍스트가 없는 상태"** 가 문제의 본질입니다.

## 진단 5줄

1. **구조적 원인** — 어린이집·아파트·병원·편의시설 등 수만 개 상세 페이지가 자동 생성되며, 각 페이지는 표·목록·지도 위주이고 독창적 문장이 사실상 없음. 구글 정책상 "피드를 고유한 이점 없이 재현"하면 스크래핑으로 간주됨(구글 검색 스팸 정책, A급 출처).
2. **비교 사례가 명확** — 거의 동일한 유형의 한국 서비스 '주거나침반(jugeo.co.kr)'도 같은 사유로 반복 거절됨(구글 애드센스 커뮤니티, 2026-06). 자가진단 내용("표 위주라 서술형 텍스트 부족")이 imjangon과 판박이.
3. **원문 콘텐츠 총량 부족** — 실제 서술형 원문은 `/guide`의 약 14편뿐. 커뮤니티 통설(비공식)은 20~30편·운영 1~3개월 이상을 권장.
4. **부가가치가 텍스트로 표현되지 않음** — 반경 1km 실거래가·도보 시간·인프라 근접성 등 훌륭한 '해석 재료'가 있으나, 이를 문장으로 설명하지 않아 봇이 가치를 인식 못 함.
5. **기본기는 이미 갖춤** — About·개인정보처리방침·데이터출처·FAQ·문의 페이지 보유. 이건 문제가 아님 → 남은 과제는 오직 '원본 텍스트 부가가치'.

## 개선 우선순위 (Top 5)

| 우선순위 | 조치 | 기대 효과 |
|---|---|---|
| **P0** | 상세 페이지 템플릿에 **데이터 해석형 서술 단락** 자동 삽입(단순 표 반복 금지, 비교·평가·맥락 추가) | 페이지별 고유 텍스트 확보, 스크래핑 오인 탈출 |
| **P0** | `/guide`를 **25~40편 이상 심층 문서**로 확대, 상세 페이지에서 관련 가이드 상호링크 | '원본 콘텐츠 사이트' 신호 강화 |
| **P1** | 가장 얇은 대량 페이지(빈 엔티티·페이지네이션 셸)는 **noindex**, 알짜 허브만 색인 | thin page 비율 감소, 사이트 평균 품질 상승 |
| **P1** | 지역·학군·시세 **분석형 허브 페이지**(에디토리얼) 신설 | 사람이 쓴 고유 분석 = 최고 신호 |
| **P1** | E-E-A-T 강화: 운영자·데이터 방법론·갱신일 명시, SSR로 텍스트 크롤 보장 | 신뢰도·크롤러 가독성 향상 |

## 재신청 전 체크리스트

- [ ] 대표 상세 페이지 20개에 3~5문장 이상 고유 해석 텍스트가 렌더링되는가(자바스크립트 없이도 보이는가)?
